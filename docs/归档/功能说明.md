# 功能说明（详细版）

## 1. 产品简介

本地 TXT 小说阅读器（浏览器版）：在 Chrome 中打开本地 TXT 文件，自动识别编码与章节，以起点中文网风格阅读页阅读；纯本地运行，文件不上传、不联网、无账号。

## 2. 运行方式

```bash
npm install
npm run dev          # 开发模式 → Chrome 打开 http://localhost:5173
npm run build        # 生产构建 → dist/index.html（单文件，Chrome 双击即用）
npm run test:smoke   # 核心逻辑冒烟测试
```

## 3. 界面与交互

### 书架页

- “打开 TXT”按钮 / 拖拽文件到页面 / 文件选择器（不支持 File System Access API 的浏览器自动回退）；
- 分区：收藏、最近阅读、全部书籍；
- 每本书记录：书名、大小、编码、章节数、最后打开时间、阅读进度、收藏状态；
- 点击“阅读”重新打开（Chrome 通过保存的文件句柄免选文件续读）。

### 阅读页

- 顶部：返回书架、书名、当前章节名；章节翻页模式下右侧显示“第 X / N 章 · Y%”；
- 正文：纸张式底色（与两侧背景深浅区分）、首行缩进两字符、居中单栏、可调宽度；
- 正文右侧：竖排工具栏（目录 / 设置 / 主题色板）；
- 底部：仅章节翻页模式显示“上一章 / 下一章”（与正文同宽居中）；滚动模式整条隐藏。

### 目录面板

- 从左侧滑出，覆盖正文，半透明遮罩；
- 两列网格显示章节名，支持按名称搜索、点击跳转；
- 右侧边缘可拖拽调宽（300–900px），宽度自动记忆。

### 设置面板

- 主题（日间 / 米黄 / 护眼绿 / 夜间）；
- 字体（宋体 / 黑体 / 微软雅黑 / 楷体 / 等线 / 思源宋体）；
- 字号（12–28px，A−/A+，快捷键 Ctrl+±）；
- 行距（1.2–2.6）、段距（0–1.5em）；
- 对齐方式（左对齐 / 两端对齐）；
- 正文最大宽度（560–1100px）；
- 阅读模式（章节翻页 / 滚动翻页）；
- 文件编码（切换后即时重新解析章节）。

> 阅读设置是**全局设置**（作用于整个阅读器，不针对某本书），每次修改都会自动保存，下次打开继续沿用。
>
> **首次打开时的默认值**：微软雅黑字体、夜间主题、字号 24px、行距 1.9、段距 0.8em、正文最大宽度 1000px、滚动翻页。

## 4. 阅读模式

- **章节翻页**：一次一章；底部显示上一章/下一章；滚到章末不自动加载；进度显示在顶栏。
- **滚动翻页**：滚到距底部约 600px 自动追加下一章；隐藏翻页按钮与底部栏；当前章节按视口顶部判定；自动卸载当前章节前 15 章以外的内容，弱机器也流畅。

## 5. 快捷键

| 按键 | 功能 |
|---|---|
| `←` / `→` | 上一章 / 下一章 |
| `PageUp` / `PageDown` | 上 / 下翻页 |
| `Home` / `End` | 章首 / 章尾 |
| `Ctrl + +/-` | 增大 / 减小字号 |
| `Esc` | 隐藏 / 显示顶栏（与底部栏） |
| `t` | 打开 / 关闭目录 |
| `s` | 打开 / 关闭设置 |

## 6. 编码与章节识别

- 自动识别：BOM → UTF-16 空字节模式 → 严格 UTF-8 校验（含中文得分对比，避免 GBK 误判）→ GB18030 / Big5 打分；
- 支持：UTF-8（含 BOM）、UTF-16 LE/BE、GB18030/GBK、Big5、Windows ANSI；
- 识别失败可手动选择编码并即时重新解析；
- 章节规则表（可扩展）：`第X章/回/节/卷/集/篇/部`、`楔子/序章/序言/引子/引言/前言/番外/尾声/后记/终章/大结局`、`Chapter N`；
- 4MB 分块扫描 + 行尾 carry，输出“章节名 + 字节偏移”索引，不整本读入内存（20MB 约 125ms）；无章节文件回退为整本一章。

## 7. 数据存储

- IndexedDB（库名 `txt-reader`）：
  - `books`：书架（id、书名、文件名、大小、最后打开时间、收藏、编码、章节数）；
  - `progress`：每本书的进度（章节索引、章节内滚动偏移、更新时间）；
  - `handles`：File System Access API 文件句柄（免选文件续读）。
- localStorage：`txt-reader-settings`（阅读设置）。
- Chrome 路径：`C:\Users\<用户名>\AppData\Local\Google\Chrome\User Data\Default\IndexedDB\http_localhost_5173.indexeddb.leveldb`；设置在同级 `Local Storage\leveldb\`。
- 直观查看：F12 → Application → IndexedDB / Local Storage。
- Edge 同理（`...\Microsoft\Edge\User Data\Default\...`），数据与 Chrome 互相独立。
- 数据量极小（千本书约 1–2MB），不占系统资源。

## 8. 迁移

- 仅阅读：复制 `dist/index.html` 到新电脑，Chrome 双击即用；书库/进度需在新电脑重新导入（数据在浏览器内，不随文件走）。
- 继续开发：复制整个项目目录（排除 node_modules、dist、.tmp），安装 Node.js 后 `npm install && npm run dev`。

## 9. 技术架构

```text
src/
  App.tsx                  # 视图切换、导入流程、全局状态
  lib/encoding.ts          # 编码检测与解码
  lib/chapters.ts          # 章节规则与分块扫描
  lib/storage.ts           # IndexedDB 封装
  lib/fileOpen.ts          # 文件选择 / 句柄持久化
  lib/settings.ts          # 阅读设置
  components/              # 书架、阅读页、目录、设置
scripts/smoke-test.ts      # 核心逻辑冒烟测试
```

## 10. 已知限制与后续规划

- 仅支持 TXT（EPUB/PDF 等按需求暂不实现）；
- 硬换行段落合并、用户自定义章节规则未实现；
- 书架排序/筛选、阅读统计、本地搜索未实现；
- 书库/进度导出导入未实现（数据留在浏览器内）。
