## 第 3 轮：产品形态转向——浏览器 + 起点风格

**用户要求**：不要桌面端，希望在谷歌浏览器里直接浏览 TXT；阅读页类似起点中文网网页模式。

**处理**：
- 放弃桌面端技术栈，改为纯浏览器 Web 应用；
- 搭建 Vite + React 19 + TypeScript 项目骨架；
- 实现核心模块：编码识别（BOM/UTF-16/UTF-8/GB18030/Big5 打分）、分块章节索引、IndexedDB 书库/进度/文件句柄、File System Access API；
- 实现起点风格阅读页、书架页、目录侧栏、设置面板、主题系统；
- 编写核心逻辑冒烟测试并修复编码误判等缺陷；构建通过。

**结果**：浏览器版第一版完成，开发服务器在 http://localhost:5173/ 可访问；`npm run build` 产出单文件 `dist/index.html`。

## 关键结论备忘

- 产品形态：纯浏览器本地 TXT 阅读器（起点风格），非桌面应用；
- 技术栈：Vite + React 19 + TypeScript + IndexedDB + File System Access API；
- 不借鉴任何项目代码，仅参考设计；MIT License；
- 数据存储于浏览器（IndexedDB/localStorage），随浏览器配置存在，不随文件迁移；
- 已修复的关键问题：StrictMode 覆盖进度、GBK 误判为 UTF-8、UTF-16 小文件识别失败、滚动模式 DOM 无限增长。
